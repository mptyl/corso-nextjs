# Corso Next.js + FastAPI

Benvenuto al corso pratico su **Next.js 16 e FastAPI**!

## Obiettivi del corso

- Capire l'architettura di un'applicazione web moderna con frontend e backend separati
- Leggere, capire e modificare codice Next.js e FastAPI
- Usare Claude Code come coding agent per sviluppare componenti
- Costruire una mini-applicazione RAG ispirata ad AthenaAI

## Lezioni

| # | Argomento | Tempo |
|---|-----------|-------|
| 0 | Setup: ambiente e struttura del progetto | 30 min |
| 1 | Backend: FastAPI, rotte REST | 60 min |
| 2 | Frontend: Next.js, React, Tailwind | 60 min |
| 3 | Collegare frontend e backend | 60 min |
| 4 | RAG su file di testo | 60 min |
| 5 | Chat UI: componente chat con React | 60 min |
| 6 | Deploy: build di produzione | 30 min |
| 7 | Riepilogo e corrispondenza con AthenaAI | 15 min |

---

> **Nota:** Segui le lezioni in ordine — ogni lezione costruisce su quella precedente.
